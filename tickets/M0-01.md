## Acceptance criteria
- AC1: docs/fork/mobile-plan.md: how apps/mobile builds (Expo, EAS profiles, native modules), what can be built on Linux and in GitHub Actions (Android) versus what needs a Mac or EAS cloud (iOS)

- AC3: needs-you items with costs: Expo account (free tier), Google Play developer account (one-time fee, optional; sideloading needs none), Apple Developer Program (yearly fee, needed for any iPhone install), Cloudflare and Clerk accounts for Enigma's own relay
