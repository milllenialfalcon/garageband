## What and why
Research models read web pages that may carry hidden instructions, so they must not be able to run commands, edit files or read the box's logins.

## Acceptance criteria
- AC1: The free OpenCode research models run with shell, edit and write denied (an OpenCode agent or permission config; find the mechanism in OpenCode's docs or source)
- AC2: Proof: a test research task told to run `ls ~` and to write a file is refused both times
- AC3: If it can't be enforced: research tasks get only a URL list and return text, and the Chief records the gap as a needs-you item
- AC4: Result in .factory/reports/a0-research-sandbox.md

## Pointers
- Prompt injection through fetched pages is the main way an unattended factory gets attacked.
